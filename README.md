# JwtAuthService

[![Python Version](https://img.shields.io/badge/python-3.9%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

A production‑ready JWT authentication service built with **FastAPI**. 
It demonstrates clean architecture, configuration handling, logging, type hints,
and comprehensive testing.

## Features

- Secure password hashing (`passlib` + bcrypt)
- JWT creation & verification (`python-jose`)
- Environment‑based configuration (`pydantic` + `python-dotenv`)
- Centralised logging
- Structured error handling
- Fully typed code
- Docker‑friendly (environment variables)
